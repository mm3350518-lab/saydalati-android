# صيدليتي — مشروع تطبيق أندرويد وموقع

## الملفات
- `www/index.html`: اللعبة المطوّرة وتعمل مباشرة من المتصفح.
- `package.json` و`capacitor.config.json`: إعدادات تغليفها كتطبيق Android باستخدام Capacitor.

## تشغيل الموقع
ارفع ملف `www/index.html` إلى أي استضافة صفحات ثابتة مثل GitHub Pages أو Netlify، أو افتحه مباشرة في المتصفح.

## بناء APK
يتطلب بناء APK بيئة Android SDK/JDK. من كمبيوتر أو بيئة بناء سحابية:
1. ثبّت Node.js LTS وAndroid Studio مع Android SDK.
2. فك ضغط المشروع وافتح الطرفية داخل المجلد.
3. نفّذ:
   ```bash
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. في Android Studio اختر **Build > Build APK(s)**. للرفع إلى Google Play أنشئ **Signed App Bundle (AAB)** من قائمة Build > Generate Signed Bundle / APK.
5. اختبر التطبيق على جهاز فعلي، وراجع محتوى الأدوية والجرعات مع مراجع موثوقة قبل أي استخدام تعليمي رسمي.

## ملاحظات
- هذه الحزمة مصدر مشروع جاهز للتغليف وليست ملف APK مبنياً أو موقعاً.
- حفظ التقدم محلي على نفس المتصفح/الجهاز باستخدام localStorage؛ لا تتم مزامنته تلقائياً بين الأجهزة.
- خيار English يترجم عناصر واجهة أساسية فقط حالياً؛ محتوى الحالات وموسوعة الأدوية ما زال عربياً ويحتاج ترجمة تحريرية كاملة في إصدار لاحق.
- اللعبة تعليمية وليست أداة لاتخاذ قرارات علاجية حقيقية.
